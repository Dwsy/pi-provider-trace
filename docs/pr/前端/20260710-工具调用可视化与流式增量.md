# 工具调用可视化与流式增量

## 背景与目的

Coding Agent 高频使用工具调用，但原 Streaming 面板只合并文本 delta。该变更将原始 provider SSE 重放为可读、可实时更新的工具调用卡片，并关联下一次模型请求提交的工具结果。

## 关联 Issue

- `docs/issues/前端/20260710-工具调用可视化与流式增量.md`

## 变更内容

- 为 OpenAI Chat Completions、OpenAI Responses 和 Anthropic 增加工具调用 SSE delta 归一化。
- 以 call id 优先、choice/index/item id 兜底维护多工具调用的独立参数缓冲。
- 在 Streaming 面板展示工具名、partial/full arguments、流式/等待/已返回状态与 tool result。
- 仅从选中 exchange 结束后的请求中关联结果；同 id 多结果保留最早匹配项。
- Exchanges 列表增加工具调用数量和执行状态徽章。
- 新增纯 Node 协议回放测试，以及中英文 README 说明。

## 验证

- [x] `npm test`

- [x] 浏览器控制台无错误。

## 风险与回滚

- **风险**：provider 引入未识别的事件命名时，原始 SSE 仍在详情中可见，只是不会生成结构化卡片。
- **回滚**：回退 `public/js/lib/sse.js`、`stream-tool-calls.js`、Streaming panel/list 与对应样式即可；wire capture 格式和服务端 API 未变。

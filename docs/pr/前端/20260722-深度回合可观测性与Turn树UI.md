# PR: 深度回合可观测性与 Turn 树 UI

## Summary

对齐 pi-langfuse 的 prompt → turn → generation/tool/message 模型：

1. **捕获**：`pi-events.ts` 写入有界全文（input / tool I/O / message / turn）+ `turnIndex`/`exchangeId`
2. **模型**：`buildSessionTree()` 将 pi_event 与 HTTP exchange 关联成会话树
3. **UI**：默认回合树导航；generation 保留 wire 证据页签；可切 HTTP 请求账本

## Files

- `src/pi-events.ts` — 全文捕获
- `src/logger.ts` — TraceRecord 关联字段
- `public/js/model.js` — 会话树

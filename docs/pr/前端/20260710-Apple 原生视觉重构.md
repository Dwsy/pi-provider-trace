# Apple 原生视觉重构

## 关联 Issue

- `docs/issues/前端/20260710-Apple 原生视觉重构.md`

## 变更内容

- 替换 Factory 棕灰色板与远程字体，采用 Apple 浅/暗系统背景、文字和语义色。
- 使用系统字体、半透明材质、克制阴影、系统级圆角与蓝色焦点反馈。
- 重构 Header、List、Tabs、详情卡片、表单与工具调用卡的视觉层级。
- 移除模拟窗口噪点和工业风装饰；保留追踪功能与多文件原生前端架构。
- 为减少动态效果与透明度偏好提供降级样式。
- 修复移动端三栏压缩：Header 自动换行，所有 Tabs 以 2×4 网格展示。

## 验证

- [x] `npm test`
- [x] `git diff --check`
- [x] 浏览器浅/暗主题 token 与系统字体检查。
- [x] iPhone 14：无水平溢出，主面板宽度等于视口，8 个 Tabs 全部可见。
- [x] 浏览器控制台无错误。

## 风险与回滚

- **风险**：仅 CSS 重构；旧浏览器不支持 `backdrop-filter` 时仍可显示为不透明表面。
- **回滚**：恢复 `public/css/tokens.css` 与 `public/css/chrome.css`，不会影响 SSE/HTTP 捕获数据。
